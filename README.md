# Mi Portafolio Web Profesional

Bienvenido al repositorio de mi portafolio web personal. Este proyecto ha sido desarrollado como una plataforma responsive, accesible y optimizada para presentar mis proyectos, habilidades e información de contacto.

## 🚀 Características
- **Diseño Responsive:** Adaptado para dispositivos móviles, tablets y escritorio.
- **Modo Oscuro / Claro:** Alternador dinámico de tema con persistencia mediante JavaScript.
- **Menú Navegación Móvil:** Menú hamburguesa interactivo para pantallas pequeñas.
- **Alto Rendimiento:** Optimizado para ofrecer tiempos de carga mínimos.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica de la página.
- **CSS3:** Estilos personalizados, Flexbox/Grid, variables CSS y media queries.
- **JavaScript (ES6+):** Lógica interactiva para el menú móvil y cambio de tema.
